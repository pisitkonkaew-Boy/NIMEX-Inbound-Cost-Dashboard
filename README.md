# NIMEX Inbound Cost Dashboard

หน้าเว็บต้นทุนงานเข้ารับเทียบรายได้ (DC 610 / 621 / 691 · AB แห้ง / CC เย็น) อ่านข้อมูลจาก Google Sheet ผ่าน Apps Script

- repo นี้ไม่มีตัวเลขจริง ข้อมูลทั้งหมดอยู่ใน Google Sheet ห้ามนำไฟล์รายงาน NIMEX06006 ขึ้น repo
- repo เป็นสาธารณะ และ Apps Script เปิดอ่านให้ทุกคนที่มีลิงก์ ใครมีลิงก์ก็เห็นข้อมูลบนแดชบอร์ด
- ผู้ชมทั่วไปเปิดลิงก์ตามปกติ ผู้ดูแลเปิดลิงก์แล้วต่อท้ายด้วย `#admin` แล้วใส่รหัส
- รหัสผู้ดูแลเก็บใน Script Properties ชื่อ `ADMIN_KEY` ของ Apps Script เท่านั้น
- ที่อยู่ระบบข้อมูลอยู่ใน `config.js` เมื่อแก้ไฟล์หน้าเว็บ ให้เพิ่มเลข `NIM_V` เพื่อล้างแคช
- สูตรคำนวณทั้งหมดอยู่ใน `nim-calc.js` (ไฟล์เดิม ไม่ได้แก้) โค้ดฝั่ง Apps Script อยู่ใน `Code.gs.txt`

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| index.html | โครงหน้า หน้าปก ฟอนต์ Prompt ฝังในไฟล์ |
| config.js | URL ของ Apps Script และเลขเวอร์ชัน |
| boot.js | โหลดข้อมูล ตรวจรหัสผู้ดูแล แล้วเปิดแดชบอร์ด |
| nim-calc.js | การคำนวณ (ไม่ได้แก้) |
| app.js / app.css | หน้าจอ ตัวกรอง กราฟ ตาราง |
| admin.js | ตั้งค่า เติมไฟล์ ตรวจสอบข้อมูล แชร์และส่งออก (โหลดเฉพาะผู้ดูแล) |
| logo.png / cover.jpg | โลโก้ และภาพหน้าปก (ใช้เป็นรูปตัวอย่างลิงก์ใน LINE ด้วย) |
